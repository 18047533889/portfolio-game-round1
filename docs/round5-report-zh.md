# Portfolio Game 第五轮：以替代风险度量做组合优化

**提交物**：`submission/portfolio_round5.py`（单文件，886 行，自包含）
**冻结参数**：`anchor_penalty = 0.5`、`downside_mix = 0.5`、`half_life = 63`、`recent_mix = 0.25`、`gross_budget = 1.0`
**契约**：`shortselling = FALSE`、`budget = 1.0`、`lookback = 252`、`optimize_every = 20`、`weight_drift = TRUE`

---

## 一、本轮规则，以及它为什么把方向整个反过来

| 项 | R3 | **R5** |
|---|---|---|
| 禁令 | EWP / IVP / SCM-GMVP | **完全相同** |
| `shortselling` | TRUE | **FALSE** |
| 参数名 | leverage 1.5 | **budget 1.0** |
| `lookback` | 126 | **252** |
| 年化收益 | 20% | **出局** |
| 年化波动率 | 10% | 10% |
| 最大回撤 | 出局 | **10%（回归）** |
| **CVaR(95%)** | — | **10%（新）** |
| 失败率 | 70% | 70% |

三条推论，每一条都改变了参数：

1. **约束这次被写死了。** 邮件原文："weights must be nonnegative and sum to 1... holding cash
   through unallocated weights is not permitted"。前三轮我一直在处理 `leverage` 的语义歧义
   （它是否约束 gross 敞口），**这轮不存在歧义**：非负 + 满仓，做空明确禁止。

2. **评分里没有任何收益项。** 30% 全是风险指标（波动 10% + 回撤 10% + CVaR 10%）。
   R3 是"收益权重是波动的 2 倍"，R5 是"没有收益轴可交易"。**所以
   R3 选的 `anchor_penalty = 16`（靠近 HRP 锚、换收益）在这轮是错的方向**——锚项在这里
   是纯粹的代价，因为它是唯一把组合从"最低风险"拉开的东西。

3. **`CVaR(95%)` 进场，而且本轮标题就是 "alternative risk measures"。**
   三个被评分的风险里只有一个（波动率）是方差在管的；回撤和 CVaR 都是左尾量。
   **方差不等于尾部。**

## 二、唯一的实质改动：把协方差与半协方差混合

目标函数仍然是

$$\min_{w}\ \frac{w^\top C w}{b^\top C b} + \lambda \frac{\lVert w-b\rVert^2}{\lVert b\rVert^2}
\quad\text{s.t.}\quad \sum w = 1,\ w \ge 0$$

其中 $b$ 是 HRP 锚、$C$ 是 Ledoit-Wolf 收缩 + Marchenko-Pastur 去噪的协方差。
本轮加的是把 $C$ 换成

$$C_{\text{mix}} = (1-m)\,C + m\,S,\qquad
S = \text{cov}\big(r \odot \mathbb{1}[r < \bar r]\big)$$

即**仅对低于均值的偏差**估一个半协方差，再按 $m$ 混合。锚 $b$ 也按 $C_{\text{mix}}$ 重算，
所以它在同一个风险度量下是自洽的。

**为什么用这个而不是直接上 CVaR 线性规划。** 说清取舍：

- 直接优化 CVaR 是 LP，要引入辅助变量 $u_i \ge -\sum_j w_j r_{ij} - \text{VaR}$，
  求解要换引擎；而**半协方差保持二次型**，求解器、投影算子、对偶间隙证书
  **一个字都不用改**，仍然验到机器精度。
- 半协方差是左尾的一个二次代理，不是 CVaR 本身。**它是代理，不是等价。**

**实测（sp500，出厂惩罚系数）**：

| | 年化波动率 | 最大回撤 | CVaR(95%) | 到被禁 SCM-GMVP 的 L1 |
|---|---|---|---|---|
| `p=0.05, m=0` | 14.8873% | 42.4688% | 2.1276% | 0.282 |
| `p=0.05, m=0.5` | **14.8191%** | **37.1020%** | **2.1123%** | **0.364** |
| `p=0.5, m=0` | 15.3988% | 51.3538% | 2.1939% | 0.544 |
| **`p=0.5, m=0.5`（出厂）** | 15.5417% | **48.3420%** | 2.2198% | 0.629 |

`p=0.05` 那一行是本轮**唯一一次**"三项被评分风险同时改善、同时合规距离还变大"的改动
（回撤 −5.4pp）。**但它在出厂惩罚下只对 sp500 与 factors 成立**，ftse100 上回撤反而
从 42.33% 恶化到 46.71%（+4.38pp），波动率和 CVaR 也略升。这一条**逐数据集反转**，
如实记录，不做平滑。

**为什么还是留着它。** 在出厂惩罚系数下，统一对手池里的得分是
`m=0.5`：sp500 0.5783 / ftse100 0.5783 / factors 0.5783；
`m=0`：0.5683 / 0.5783 / 0.5783。**在出厂这个点上 `m=0.5` 不劣于 `m=0`**，
而它是本轮主题的实质回应。**但它不是免费午餐**，ftse100 的回撤代价是真的。

## 三、惩罚系数：这轮的定价权在合规，不在评分

这是本轮唯一真正困难的取舍，也是我唯一**主动放弃分数**的地方。

### 3.1 评分想把惩罚压到零

评分里没有收益项，所以**锚项是纯粹的代价**。实测（统一对手池，12 个参考方法）：

| 设置 | sp500 | ftse100 | factors | 均值 | 最差 |
|---|---|---|---|---|---|
| `p=0.05 mix=0.5` | **0.7083** | 0.6183 | 0.6183 | **0.6483** | 0.6183 |
| `p=0.05 mix=0.0` | 0.6783 | 0.6083 | 0.5883 | 0.6250 | 0.5883 |
| `p=0.25 mix=0.5` | 0.5983 | 0.5883 | 0.5883 | 0.5917 | 0.5883 |
| **`p=0.50 mix=0.5`（出厂）** | 0.5783 | 0.5783 | 0.5783 | **0.5783** | 0.5783 |
| `p=1.00 mix=0.5` | 0.5383 | 0.5783 | 0.5783 | 0.5650 | 0.5383 |

参考方法（同一池）：`NCO` 0.6433、`MinVariance(Denoise)` 0.6517、**`MinVariance(SCM)`（被禁的）** 0.6276、
`MinVariance(Shrunk)` 0.6044、`MaxDiversification` 0.4257、`HRP` 0.0175（失败 99.8%）。

**评分单调地奖励"更低的惩罚"**——因为惩罚越低越接近最小方差。

### 3.2 而惩罚越低，越接近被禁的组合

所以必须**逐折**测"离被禁的 SCM-GMVP 有多远"，且看**最差折**而不是中位数。
工具：`tools/round5_compliance_check.py`（每一折都用同一训练窗口重建 long-only SCM-GMVP 再比）。

| 数据集 | `p` | L1 中位 | **L1 最差折** | 与 GMVP 最大相关 | 低于 0.10 的折数 |
|---|---|---|---|---|---|
| sp500 | 0.10 | 0.415 | 0.159 | 0.990 | 0 |
| sp500 | 0.25 | 0.524 | 0.226 | 0.989 | 0 |
| sp500 | **0.50** | 0.629 | **0.240** | 0.987 | 0 |
| sp500 | 1.00 | 0.725 | 0.243 | 0.983 | 0 |
| ftse100 | **0.50** | 0.856 | **0.487** | 0.939 | 0 |
| factors | **0.10** | 0.584 | **0.000** | **1.0000** | **7 / 100** |
| factors | 0.25 | 0.828 | 0.173 | 0.9982 | 0 |
| factors | **0.50** | 0.985 | **0.353** | 0.9977 | 0 |

**`p=0.10` 在 5 资产面板上有 7 折的 L1 精确为 0——那 7 折我们返回的就是被禁的组合本身。**
而中位数 0.584 完全掩盖了它。**这就是为什么必须看最差折。**

### 3.3 定案：`p = 0.50`

规则（先写死再选，避免事后合理化）：**任何一折的 L1 都不得低于 0.10**
（即 R2 已诊断违规尺度 0.030 的 3.3 倍）。

- `p ≤ 0.10`：**不合格**（factors 有 7 折为 0）
- `p = 0.25`：合格，最差折 0.173
- `p = 0.50`：合格，最差折 0.240 / 0.487 / 0.353 → **2.4× 到 4.9× 余量**

在合格集合里为什么不选分数更高的 0.25：**束缚在 sp500。**
sp500 的最差折从 `p=0.25` 的 0.226 到 `p=1.0` 的 0.243，**只动了 0.017**——
不管怎么加惩罚，sp500 总有某折被最小方差方向主导（大概率是合格资产数退化的折）。
所以把 `p` 从 0.5 加到 1.0，**在真正构成约束的数据集上什么都没买到**，
却要付 0.010 的分。而 `p` 从 0.5 降到 0.25 会损失 0.013 的分去换一个只在
非束缚数据集上变大的余量。

**`p=0.50` 就是"以最小分数代价满足底线"的那个点。**
相对评分最优的 0.05 它付了 **0.070**，这是本轮的合规成本，如实报出。

## 四、一个必须说清的量度边界：L1 距离是诊断，不是判据

如果只看"某折 L1=0"，会得出错误的结论。**对 11 个合法参考方法做同样的逐折测量**
（`research/round5/calibrate_margin.py`）：

| sp500 上的方法 | L1 中位 | **L1 最差折** |
|---|---|---|
| `EqualWeighted`（**按名字被禁**） | 1.108 | 0.566 |
| `InverseVolatility`（**按名字被禁**） | 0.914 | 0.384 |
| `RiskBudgeting` | 0.887 | 0.405 |
| `MaxDiversification` | 0.922 | 0.481 |
| `MinVariance(Shrunk)` | 0.223 | **0.078** |
| `MinVariance(Denoise)` | 0.315 | **0.066** |
| **`NCO`（完全合法）** | 0.318 | **0.000** |

三个结论，每一个都影响判断：

1. **`NCO` 这个完全合法的方法，在 sp500 与 factors 上的最差折也是 L1 = 0.000。**
   所以「某一折与被禁组合重合」本身**不构成违规证据**。
2. **被"按名字"禁止的 EWP / IVP 离被禁的 SCM-GMVP 最远（0.9~1.1）。**
   所以这个 L1 根本不是合规度量，它度量的是「有多像最小方差」。
3. **合法但距离最近的是 `MinVariance(Denoise)` / `MinVariance(Shrunk)`** ——
   这两个正是本项目在 R2 用测量**驳倒**过的那个辩解（"我用了收缩/去噪协方差所以我不是
   SCM-GMVP"，5 资产上与 SCM-GMVP 相关性 0.999）。**它们的距离小是有原因的。**

所以上面那条底线规则真正排除的**不是"某一折巧合"，而是"锚已经停止起作用的系统性区间"**
——这是**构造路径**的性质，不是单折的性质。我们的构造路径是：
收缩 + 去噪协方差 + 锚正则 + 带证书的投影梯度求解，**没有任何一条代码路径形成
`1/n`、`1/σ` 或 `Σ^{-1}1`**。

## 六、必须说清的边界

1. **「0 失败」不等于「隐藏测试一定通过」。** 上面覆盖的是 skfolio 自带数据集，
   不是老师的真实测试集。它证明的是：在能构造出的最接近场景里不失败、不产出被禁组合。
2. **出厂设置不是模拟得分的最高者，而且差得不小（0.070）。**
   我选它是因为评分在无约束时会把惩罚推向 0，而 0 附近就是被禁组合。
   **这是主动用分数买合规，不是"它更优"。**
3. **半协方差是左尾的二次代理，不是 CVaR 等价物。** 它在这轮的三项指标上
   有帮助（sp500/factors），在 ftse100 上对回撤有害。**逐数据集反转，不保证泛化。**
4. **`anchor_penalty` 和 `downside_mix` 是在同一批公开数据集上选出来的。**
   这是选型，不是样本外验证。真正的样本外只有老师的隐藏测试集。
5. **本轮的 L1 距离量度有明确适用边界**（见 §4）：它排除的是"系统性贴近最小方差"，
   而不是任何单折巧合。
