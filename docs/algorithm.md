# 算法解释与工程取舍

## 输入和输出

输入 X 的行是观测期、列是给定资产；元素是简单收益率，不是价格、因子得分或百分数整数。输出 w 的每一项对应原始资产列。正式模型只读最后 252 行；没有标签 y、外部现金资产或跨次调用的状态依赖。

## 风险估计

先移除一个共同的正数尺度再求平方，避免极大的有限观测使数值溢出。对完整观测估计 Ledoit–Wolf 协方差 C_s，提取长期相关矩阵 R_s。

对 R_s 再做一次 **Marchenko–Pastur 去噪**。把 R_s 标准化后，若真实相关是单位阵，其经验特征值密度收敛到 MP 律，支撑区间上边缘为

\[
\lambda_+=\left(1+\frac{1}{\sqrt{q}}\right)^2,\qquad q=\frac{T}{N}.
\]

低于 \lambda_+ 的特征值方向与抽样噪声不可区分，因此把它们全部替换为其共同均值（保迹选择），重建矩阵后再缩放回单位对角。这一步是**降低估计方差**，不是更换估计目标；对角缩放会轻微扰动谱，所以噪声带只是被大幅压平而非压成常数。若 `n_assets < 2` 或 `T <= N + 2`，样本无法分辨信号与噪声，此时**直接跳过**去噪，而不是做一个不可靠的近似。

对近期收益给予 a_t ∝ 2^{-age_t/h} 的权重，以 1-sum(a_t²) 修正加权方差，得到各资产近期波动对角矩阵 D_h。

C = (1-rho) C_s + rho D_h R_s D_h。

再对称化并对小特征值施加相对数值下限。最终乘除同一个正数不会改变归一化优化目标。共同有效行被筛选后，半衰期按保留下来的观测计，不声称恢复了缺失交易日；数据过稀时直接降级，绝不填零伪造低风险。

## 树结构 HRP 参考配置

距离 d_ij=sqrt((1-corr_ij)/2)，单连接聚类。递归使用真实聚类树的左右子节点：每个子组以逆方差权重估计组风险，按左右组风险的反比划分该节点的资金。

这里采用 tree-split HRP，而不是把一个叶子排序表机械地二分。它让非并列情形下的资产重排列保持等价；精确并列仍可能依赖输入列顺序。它也不同于某些 skfolio HRP/Schur 的叶序二分实现，比较结果应标明此区别。

## 凸目标与求解

f(w)=w'Cw/(b'Cb)+lambda*(w-b)'(w-b)/(b'b)，约束 w>=0、sum(w)=1。

令 Q=C/(b'Cb)+lambda I/(b'b)，p=lambda b/(b'b)，则 f(w)=w'Qw-2p'w+lambda。
梯度 g(w)=2(Qw-p)。取 L=2*max_i sum_j |Q_ij|，它是 Hessian 谱范数的一个上界。

每步将 y-g(y)/L 投影到非负满仓单纯形，使用加速和目标上升时的重启。最多 600 次迭代；这限制计算次数，不代表任意机器上的严格墙钟超时保证。

单纯形上的一阶间隙：gap=g(w)'w-min_i g_i(w)。对凸函数，f(w)-f(w*)<=gap。代码检查 gap/(1+abs(f(w)))<=1e-8。

这说明“符合权重约束”和“达到优化精度”是两回事。未通过精度检查时保留诊断并走后备，不把未收敛点标记为主优化成功。已经通过的数值测试使用独立 SciPy SLSQP 比较最优目标与权重；CVXPY 检验属于另一独立的可选测试模块。

## 非等权与兜底

局部非等权检测用 rtol=1e-5、atol=1e-8；教师实际容差未知。若一个候选近似等权，尝试下一条风险配置路径。全部不合适时，依据可观察风险和固定列顺序选择单资产，而不是对等权添加极小扰动。

这类最终规则在退化数据下保护输出有效性，不意味着投资表现更好。报告中的 qp_objective/qp_relative_gap 对应主优化尝试；如果 anti_equal_weight_applied 或 single_asset_fallback 为真，最终投资权重不能再视为原目标的最优点。

## 为什么没有某些功能

不使用最大历史夏普，以避免未经验证的样本均值预测；不加硬性最低收益、持仓数量或固定权重上限，避免小资产池无解；不依赖上一轮对象内存，从而兼容克隆与独立窗口；不做每次 fit 内部大规模参数搜索。

对满仓多头加 lambda*||w||_1 只是常数，不能稀疏化；过强的裸 ||w||_2² 则会推向等权，因此本项目采用向数据生成的参考组合收缩。

**一句话记忆：从历史收益估计风险，向分层参考配置适度收缩，用可检查的凸优化精度和分层后备路径同时控制估计风险与运行风险。**
