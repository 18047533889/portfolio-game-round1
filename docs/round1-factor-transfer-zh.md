# 因子移植研究：A股因子 → SP500 → 组合优化端

本文件记录一次完整的因子搬运实验，结论是**不上线**。写下来是因为"没做成"和
"为什么没做成"同样有价值：它把那条路封死了，并且给出了封死它的证据。

## 0. 一句话结论

把 COS 里 A 股表现最好的因子家族（波动率 / 振幅 / 量价协方差）搬到美股 SP500
上做纯多回测，**在"随机抽股票 × 随机两年窗口"的口径下打不过什么都不做**——
最接近的组合在 120 个随机块里只在 43% 的块里改善夏普、45% 的块里改善最大回撤。
按老师的评分表（夏普 10% + 最大回撤 10% + 年化 10% + 失败率 70%），
这个倾斜在 3 个打分项里有 2 个变差，因此**不写进提交文件**。

## 1. 数据来源与取证路径

| 项 | 值 |

| 美股指数成分 | `cos://qs-cold/clean_data/us_stock/massive_data/StockIndicesComponents/`（含 `IndexName='S&P 500'`） |

A股清单规模：**263 个已产出因子**（factorminer v2.0/v2.1 + cogalpha），
其中 **104 个带 `rank_ic`**，最高 RankIC ≈ **0.0561**（`scale_range_decay`）。

按所需字段统计（出现次数）：

| 字段 | volume | close | high | low | returns | open | amt |
|---|---|---|---|---|---|---|---|
| 次数 | 220 | 213 | 138 | 122 | **81** | 56 | 45 |

**这张表直接决定了移植的天花板**：A 股头部因子的机制是"振幅强度"和"高价/低价
变动与成交量的协方差"，全部依赖 OHLCV。而 Round 1 的评分系统交给我们的是
一个 `252 × N` 的**收益率矩阵**，没有 high/low/open/volume。
`close = cumprod(1+r)` 只能还原归一化价格路径，还原不出振幅与量。
所以真正能搬的只有 `returns` 那一支——波动率复合体。

## 2. 美股侧：先造一个有说服力的靶子

用 COS 的逐日 parquet 重建了一张 **S&P 500 时点成分面板**（不是"今天的成分股回溯"，
避免幸存者偏差）：

- 3,122,695 行 / 5,760 个交易日 / 861 个历史成分股 / 2003-09-10 → 2026-08-03
- 每个交易日只保留当天确实在指数里的名字（平均 481 个）

### 2.1 一个必须先修的坑：除权日伪收益

第一次跑出来全宇宙等权账本年化 **+31.8%**，而等权 S&P 500 同期实际只有 10~12%。
逐层定位后原因是 **COS 的复权字段在一批拆股/并股日没有把收益中性化**：

| 日期 | 代码 | 面板里的 20 日收益 |
|---|---|---|
| 2014-06-09 | AAPL | +612%（7:1 拆股） |
| 2009-06-03 | AIG | +1130%（1:20 并股） |
| 2010-01-21 | BRK.B | +5314%（B 股 50:1 拆股） |
| 2011-04-08 | C | +868%（1:10 并股） |
| 2008-09-29 | WB | +57300% |

横截面的**算术平均**对这类异常毫无防御，几百个异常点就把整个水平抬高了 20 个
百分点/年。过滤 `|单日收益| > 50%`（美国大盘股单日真实波动不可能到这个量级）
共剔除 **734 个观测**（占 0.024%）后，同一账本回到：

> 等权宇宙账本：**年化 +11.61%，Sharpe 0.663，最大回撤 0.626**（275 个调仓期）

这与真实的等权 S&P 500 一致（2008 年那 62% 回撤也对得上），说明面板可信。

同时用已知个股交叉验证：AAPL 2004 全年面板 +203.3% vs 实际 +201%；XOM
2004–2024 面板 +431% vs 实际约 +400%。

### 2.2 因子体检结果（RankIC vs 未来 20 日收益）

按 3 个不重叠子区间（2004–2010 / 2011–2017 / 2018–2026）分别算，看符号是否稳定：

| 因子 | 全期 IC | t 值 | 三个子区间 IC | 只看收益可算？ |
|---|---|---|---|---|
| `cov_dhigh_dvol10` | −0.0125 | **−2.3** | −0.0202 / +0.0003 / −0.0172 | ❌ 需要 high/volume |
| `cov_dhigh_vol10` | −0.0102 | **−2.0** | −0.0219 / −0.0039 / −0.0067 | ❌ |
| `vwap_dist10` | −0.0095 | **−2.0** | −0.0193 / +0.0013 / −0.0110 | ❌ |
| `corr_vol_mkt` | +0.0158 | 1.7 | **+0.0027 / +0.0154 / +0.0258** | ✅ |
| `corr_mkt252` | +0.0154 | 1.4 | **+0.0047 / +0.0219 / +0.0181** | ✅ |
| `kurt60` | +0.0052 | 1.0 | +0.0003 / +0.0078 / +0.0067 | ✅ |
| `volofvol60` | +0.0069 | 0.7 | +0.0191 / +0.0020 / +0.0016 | ✅ |
| `mom231` | +0.0048 | 0.4 | −0.0008 / +0.0113 / +0.0037 | ✅ |
| `rv252` | +0.0100 | 0.7 | +0.0391 / **−0.0134** / +0.0076 | ✅ 符号翻转 |
| `beta252` | +0.0161 | 1.0 | +0.0363 / **−0.0000** / +0.0143 | ✅ 符号翻转 |

读数很清楚：

1. **统计上站得住的（|t| ≥ 2）全部是 OHLCV 因子**——正好是提交文件拿不到的那一支；
2. 收益可算的那一支，最强也只有 t = 1.7，而且 A 股头部因子的方向在美股
   **反了**：A 股是"波动/振幅越大、未来收益越高"（正 IC），美股量价协方差
   那一族是**负** IC；
3. 唯一在三个子区间都同号的是"与市场的相关性"（`corr_mkt252` / `corr_vol_mkt`），
   但它的经济含义就是 **高 beta / 高联动**——在长期上涨的样本里当然好看，
   代价是回撤同步放大。

## 3. 关键实验：倾斜真的能加分吗

即便单因子信号弱，也可能通过组合优化端的倾斜（tilt）转成收益。所以直接做端到端：

```
min  w'Cw/(b'Cb) + penalty·‖w−b‖²/‖b‖² − γ·s'w     s.t.  w ≥ 0, Σw = 1
```

`b` 是 HRP 树锚、`s` 是复合信号（横截面 z 分数等权平均）、`γ = 0` 就等价于现在
提交的那份文件。两个复合定义：

- **stable**：只用美股三区间同号的收益类信号（corr_mkt / corr_vol_mkt / kurt /
  volofvol / mom231）；
- **ashare_vol**：按用户的要求，直接照搬 A 股头部家族的**方向**（高波动→买入），
  用收益可算的波动率复合体实现。

### 3.1 全历史 walk-forward（老师口径：252 / 20）

| 数据集 | γ=0 | γ=0.5 | γ=1.0 | γ=2.0 |
|---|---|---|---|---|
| sp500(20) Sharpe | 1.1036 | 1.1151 | **1.1293** | 1.1038 |
| ftse100(64) Sharpe | **0.9815** | 0.9240 | 0.8240 | 0.6678 |
| factors(5) Sharpe | 0.7017 | 0.7345 | **0.7415** | 0.7270 |
| sp500_index(1) Sharpe | 0.6095 | 0.6095 | 0.6095 | 0.6095 |

**这就是典型的"把运气当本事"**：同一个 γ 在 sp500 和 factors(5) 上改善，
在 ftse100 上从 0.98 掉到 0.82。如果只用 4 个数据集里的 3 个去挑 γ，
一定会选中 γ=0.5 然后在这里翻车。

`ashare_vol` 复合更差：ftse100 Sharpe 0.9815 → 0.7635（γ=1.0），
factors(5) 0.7017 → 0.5156，而且最大回撤同步恶化
（ftse100 0.0152 → 0.0247）。

### 3.2 决定性的那一票：随机子集 × 随机两年窗口

按用户描述的"老师随机抽一部分股票、随机取两年"的口径，3 个数据集各抽 40 次
（共 120 个块），每块跑完整 walk-forward，统计倾斜战胜基线（γ=0）的比例：

| 复合 | γ | 夏普胜率 | 最大回撤胜率 | 年化胜率 |
|---|---|---|---|---|
| stable | 0.5 | 43.3% | 45.0% | 43.3% |
| stable | 1.0 | 42.5% | 37.5% | 44.2% |
| stable | 2.0 | 40.0% | 35.0% | 45.8% |
| ashare_vol | 0.5 | 38.3% | 34.2% | 55.0% |
| ashare_vol | 1.0 | 39.2% | 28.3% | 56.7% |
| ashare_vol | 2.0 | 35.8% | 20.0% | 55.0% |

- 两个复合、三个强度，**夏普胜率全部低于 50%**；
- A 股取向那一支能把年化抬到 55~57%，但代价是最大回撤胜率掉到 20~34%——
  即"用更高的回撤换更高的收益"，而回撤本身就是 10% 的评分项；
- 结论：**没有一档强度能稳定加分**，γ 越大越接近"押注高波动/高 beta"。

## 4. 决定与理由

**不上线。** 提交文件保持 γ = 0（即不含因子倾斜）。

理由，按权重排序：

1. **失败率占 70%，倾斜对它零贡献、纯增风险。** 倾斜让权重更集中
   （sp500 上最大权重即便从 0.202 压到 0.164，但 ftse100 在 γ=2 时升到 0.181），
   而集中度是回撤的直接来源；
2. **在"随机子集 × 随机两年窗"下胜率不到 50%**，没有任何统计理由相信它能在
   未公开测试集上加分；
3. **全历史结果自相矛盾**（sp500/factors 改善、ftse100 恶化），
   说明任何 γ 的选择都是对 4 个可见数据集的过拟合；
4. 提交文件每多一段逻辑就多一份崩溃面，而崩溃的代价是 70% 的分数。

## 5. 顺手得到的两条副产品

1. **COS 复权字段在拆股/并股日未中性化**（734 个观测，最高 +57300%）。
   任何在 `clean_data/us_stock` 上做多因子合成 / 组合优化的流程都该先加
   `|单日收益| > 50%` 的护栏，否则横截面算术平均会被彻底污染。
   修好后等权宇宙账本从 +31.8%/年 回到 +11.61%/年。
2. **A 股因子清单的字段依赖统计**（§1 表）表明：这批因子的边际信息主要在
   OHLCV 里，纯收益率输入能承载的部分非常有限。如果以后要做"因子 → 组合优化"
   的链路，必须让上游把 high/low/open/volume 一起交给优化端，否则这条链路
   从一开始就缺料。
